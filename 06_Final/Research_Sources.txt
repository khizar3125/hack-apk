=== VERIFIED FACTS ===

1. First Website Address: info.cern.ch
2. Creator: Tim Berners-Lee (British scientist)
3. Location: CERN (European Organization for Nuclear Research), Switzerland
4. First Server: NeXT computer
5. Operational Date: December 20, 1990
6. Public Announcement: August 6, 1991 (alt.hypertext newsgroup)
7. First Page: TheProject.html
8. Content: Information about the World Wide Web project
9. First Browser: Written by Berners-Lee, contained modern features
10. Public Release: April 30, 1993 (royalty-free)
11. W3C Founded: October 1994 at MIT
12. First Image: Uploaded by Berners-Lee in 1992
13. First External Server: SLAC (Stanford Linear Accelerator Center), December 1991
14. End of 1994: 10,000 servers, 10 million users

=== TIMELINE ===

March 1989: Tim Berners-Lee writes first WWW proposal at CERN
December 20, 1990: First website operational on NeXT computer
March 1991: Line-Mode browser available to CERN users
August 6, 1991: Public announcement on alt.hypertext newsgroup
1992: First image uploaded to web
December 1991: First external web server at SLAC
April 30, 1993: CERN releases WWW software to public domain
October 1994: W3C founded at MIT
End of 1994: 10,000 servers, 10 million users

=== ADDITIONAL CONTEXT ===

- Berners-Lee's motivation: Help scientists share knowledge across different systems
- NeXT computer: Advanced workstation with UNIX-based operating system
- Line-Mode browser: Simple browser that could run on any system
- Open source decision: Berners-Lee rejected patenting to maximize dissemination
- Impact: Web flourished due to open, royalty-free nature
